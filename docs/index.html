モバイルバッテリー

旅先の充電切れ対策に。大容量から軽量タイプまで。

選び方のポイント

  • モバイルバッテリーは、飛行機では、預け入れ荷物に入れられません。必ず、機内に持ち込む荷物に入れてください。
  • 容量は、100Wh以下が一般的な持ち込みの目安（3.7V換算で約27,000mAhまで）。詳細は航空会社の案内を確認しましょう。
  • 何回充電したいかで、容量を選びます。スマホ1回分は、おおよそ3,000〜5,000mAhが目安です。
  • PSEマークの有無、ケーブル内蔵か、同時に充電できる台数も、商品ページで確認しましょう。

変換プラグ

海外旅行の必需品。対応する国・地域は商品ページでご確認ください。

選び方のポイント

  • 国や地域によって、プラグの形が違います。行き先のタイプ（A・B・C・O・BF・SEなど）に対応しているか確認しましょう。
  • 変換プラグは、形を合わせるだけで、電圧は変えません。持っていく機器が、現地の電圧に対応しているかも確認が必要です。
  • スマホやPCの充電器は、100〜240V対応のものが多く、変換プラグだけで使えることが多いです。ヘアドライヤーなどは要注意。
  • USBポートつきだと、荷物が減ります。同時に使う台数と、出力（A・W）も見ておきましょう。
