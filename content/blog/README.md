# 旅行記（ブログ）の書き方

1. `content/blog/<slug>.html` に、記事本文（`<h2>`〜`<p>`などの中身だけ）を書く。
   見出し・段落・画像・リンクなど、`<article>` の中に入る部分のみでよい。
   商品を紹介する場合は、直接リンクを書かず、`index.html#カテゴリID` に内部リンクする
   （商品情報はトップページ側だけで管理し、二重管理を避けるため）。

2. `research/blog_posts.json` に、記事のメタ情報を1件追加する。

   ```json
   {
     "slug": "okinawa-2026-10",
     "title": "沖縄2泊3日、実際に持って行った荷物",
     "type": "diary",
     "published": "2026-10-01",
     "updated": "2026-10-01",
     "excerpt": "初めての沖縄旅行で、実際に役立った持ち物と、持って行かなくてよかったものをまとめました。"
   }
   ```

   - `type` は `"diary"`（実体験記）か `"guide"`（一般的な旅行ガイド記事）のどちらか。
   - 下書きにしたいときは `"status": "draft"` を付ける（生成されない）。`published` が未来の日付の記事も、その日まで生成されない。
   - 公開済みの記事の公開をやめたいときも、一覧から消さずに `"status": "draft"` にする（`build_site.py` が docs/ から外す）。
   - `tiktok` に動画URLを入れる場合は `https://` で始まるURLにする（それ以外はエラーで止まる）。
   - `slug` は半角英数とハイフンのみ。ファイル名（`.html`を除いた部分）と一致させる。

3. `python3 scripts/build_site.py` を実行すると、
   `docs/blog-<slug>.html`、一覧ページ `docs/blog.html`、トップページ・サイトマップがまとめて生成・点検される。
   先に `python3 scripts/build_site.py --dry-run` で、何が変わるかだけ確認できる。

4. 実際にあった旅行の内容だけを書く。行っていない旅行を「行ってきました」と書かない
   （読者に対して、事実と異なる体験談を、事実であるかのように伝えることになるため）。

## 宿の紹介ボックス（楽天トラベル）
本文に `<!-- hotel:施設番号|表示する宿名 -->` と書くと、楽天トラベルのアフィリエイトリンク付きボックスに置き換わる。
施設番号は楽天トラベルの宿ページURL（`travel.rakuten.co.jp/HOTEL/<施設番号>/...`）の数字。
アフィリエイトIDは `.env` の `RAKUTEN_AFFILIATE_ID` から読む（本文には書かない）。
